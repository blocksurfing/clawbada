## Sweep — tier=elite n=1500/cell

Each lever is a `BattleRules` field. `deep` = 2-ply search, `balanced` = 1-ply greedy,
`focus` = naive focus-fire script. Head-to-heads are mirrored, so 50.0% means no edge.
